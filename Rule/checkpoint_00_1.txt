============================================================
A. VOICE CLONING POC
============================================================

Primary candidate: VieNeu v3 Turbo.

Evaluate another candidate only if VieNeu is technically blocked, unavailable,
commercially unsuitable, or fails the required tests.

Record:
- repository/source and exact revision/version
- model ID/revision and artifact hashes
- runtime/dependency versions
- code/model/dataset/voice licenses
- redistribution/attribution requirements
- CPU/GPU support and RAM/VRAM
- offline behavior

MANDATORY LIVE POC

Use legally safe reference audio and execute:
Reference audio → conditioning/profile → Vietnamese text → cloned Vietnamese audio.

Test approximately:
- 5-second reference
- 10-second reference
- 30-second reference

For each run record:
- success/failure
- model load/generation time
- generated duration and RTF where meaningful
- RAM/VRAM and device
- artifact/checksum
- errors/warnings

Evaluate actual generated samples:
- Vietnamese pronunciation
- naturalness
- speaker similarity
- prosody
- stability

Use a documented 1–5 scale. Clearly distinguish measured data from subjective
listening scores. Do not claim quality was verified unless audio was actually heard.

OFFLINE TEST
After artifacts are installed locally, block/disconnect network where practical
and repeat generation. Record hidden downloads/network dependencies.

If VieNeu fails, preserve diagnostics and classify the cause before evaluating
an alternative. README/model-card claims are not a successful POC.

============================================================
C. LICENSE CLOSURE
============================================================

Review every proposed production artifact still PENDING from CP0 for:
- runtime/code license
- model/weights license
- dataset license where documented
- voice/speaker rights where documented
- tokenizer/phonemizer/data license
- redistribution requirements
- attribution requirements

Allowed review states only:
PENDING / APPROVED / REJECTED

APPROVED requires sufficient evidence for the intended commercial distribution.
If evidence is missing, remain PENDING and state exactly what is missing.

Record evidence sources, reviewed revisions and artifact hashes.
Do not make unsupported legal conclusions.
