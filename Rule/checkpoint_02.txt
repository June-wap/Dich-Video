PROJECT: LOCAL AI VOICE

ROLE
You are the Implementer + Tester.

PRODUCT GOAL

Build a commercial desktop application for local/offline text-to-speech.

Required V1 capabilities:
- Text-to-Speech
- Built-in voices
- Vietnamese
- English
- Chinese
- Japanese
- Spanish
- Portuguese
- Italian
- French
- Hindi
- Conversation mode
- Voice cloning
- WAV/MP3 export
- Local processing
- No paid TTS API dependency

Translation is NOT in V1 scope.

ARCHITECTURAL PRINCIPLES

1. UI must not call AI engines directly.
2. Application owns TTS Core.
3. Engines are integrated through Provider interfaces.
4. Provider != Model != Voice != VoiceProfile.
5. SQLite stores metadata/state.
6. Filesystem stores models/audio/artifacts.
7. Do not hard-code a specific AI model into product architecture.
8. Do not silently change selected voice/model during a job.
9. Jobs must eventually support cancel/retry/resume/crash recovery.
10. User text/audio/voice data must remain local by default.
11. No production model may be approved without license evidence.
12. Never commit secrets, private audio, downloaded model weights, generated audio, license keys, or machine-specific paths unless explicitly required.
13. Do not claim something is VERIFIED unless it was actually tested.

CHECKPOINT 2 — TTS ARCHITECTURE CONTRACTS

OBJECTIVE
Define stable contracts between application core and AI engines.

IMPLEMENT:
ProviderCapabilities
ModelSpec
VoiceSpec
VoiceProfileSpec
SynthesisRequest
SynthesisResult
ProviderError
GenerationParameters
AudioExportParameters

Define TTSProvider interface.

Minimum provider operations:
get_capabilities()
list_models()
list_voices()
load_model()
synthesize()
unload_model()
health_check()

Voice cloning must be optional capability.

Possible cloning contract:
validate_reference()
prepare_voice_profile()
synthesize_with_profile()

Do not require fixed-voice providers to fake cloning.

STRICT DOMAIN SEPARATION
Provider = engine/runtime adapter
Model = weights/configuration
Voice = user-selectable voice identity
VoiceProfile = cloning/conditioning data

ROUTING INVARIANT
User-selected voice identity must never be silently changed.

Routing order:
voice/profile
→ compatible model
→ language/features
→ runtime/device
→ quality
→ lock execution configuration

Create immutable execution snapshot before generation.

ERROR CONTRACT
ProviderError must contain at least:
code
message
retryable
provider
model
recovery_hint

TEST
Add contract tests and fake/mock provider tests.
