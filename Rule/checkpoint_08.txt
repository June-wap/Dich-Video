PROJECT: LOCAL AI VOICE

ROLE
You are the Implementer + Tester.

Do not redesign the product outside the checkpoint scope.

PRODUCT GOAL

Build a commercial desktop application for local/offline text-to-speech.

Required V1 capabilities:
- Text-to-Speech
- Built-in voices
- Vietnamese
- English
- Chinese
- Japanese
- Spanish
- Portuguese
- Italian
- French
- Hindi
- Conversation mode
- Voice cloning
- WAV/MP3 export
- Local processing
- No paid TTS API dependency

Translation is NOT in V1 scope.

ARCHITECTURAL PRINCIPLES

1. UI must not call AI engines directly.
2. Application owns TTS Core.
3. Engines are integrated through Provider interfaces.
4. Provider != Model != Voice != VoiceProfile.
5. SQLite stores metadata/state.
6. Filesystem stores models/audio/artifacts.
7. Do not hard-code a specific AI model into product architecture.
8. Do not silently change selected voice/model during a job.
9. Jobs must eventually support cancel/retry/resume/crash recovery.
10. User text/audio/voice data must remain local by default.
11. No production model may be approved without license evidence.
12. Never commit secrets, private audio, downloaded model weights, generated audio, license keys, or machine-specific paths unless explicitly required.
13. Do not claim something is VERIFIED unless it was actually tested.

WORKFLOW

CHECKPOINT 8 — DURABLE JOB ENGINE

OBJECTIVE
Make long-running TTS resilient.

IMPLEMENT STATE MACHINE
QUEUED
PREPROCESSING
LOADING_MODEL
GENERATING
MERGING_AUDIO
EXPORTING
CANCELLING
CANCELLED
INTERRUPTED
FAILED
COMPLETED

Define allowed transitions explicitly.

CHUNKING
Do not chunk only by character count.

Support provider limits:
characters
tokens
phonemes
model-specific limits

Prefer:
paragraph
→ sentence
→ clause/word fallback

Never split protected expressions unnecessarily.

Each chunk must have persisted state.

RESUME
Reuse completed chunk only if execution fingerprint matches.

Fingerprint should account for:
model revision
provider version
voice/profile revision
normalizer
chunker
generation parameters

CANCEL
Implement cooperative cancellation.

If worker cannot stop within safe timeout, recover worker without crashing application.

CRASH RECOVERY
Test interruption during:
preprocessing
model loading
generation
merge
export

TEST
kill worker
restart app
resume
cancel during generation
cancel near completion
failed chunk retry
configuration mismatch
model updated during interrupted job
